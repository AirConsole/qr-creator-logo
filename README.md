# Repository Archived

⚠️ This repository is archived and is no longer maintained. AirConsole does not use this library anymore.

## What This Means

- **No Further Updates:** This archive is kept for historical reference only. It does not accept new issues or pull requests.
- **No New Package Versions:** The `@airconsole/qr-creator-logo` package gets no new versions.
- **Existing Users:** The code, the [demo](https://airconsole.github.io/qr-creator-logo/demo) and the license stay available. To continue the work, fork this repository. The usage guide is in the README of the last commit before this archive notice.
- **Alternatives:** [qr-creator](https://github.com/nimiq/qr-creator) by Nimiq, the library this one extends, or [qr-code-styling](https://github.com/kozakdenys/qr-code-styling).

Thank you for your support!

*— The AirConsole Frontend Team*
